# Akademie der Drei Reiche (HTML)

## Beschreibung

Dieses Projekt stellt die Webseite einer Fantasy-Akademie dar, die aus drei magischen Reichen besteht: Magie, Artefakte und Wald.

Besucher können Informationen über die verschiedenen Reiche erhalten, ein Artefakt-Register einsehen, aktuelle Quests entdecken und sich über ein Formular bei der Gilde anmelden.

## Funktionen im Projekt

* Vorstellung der drei Reiche
* Artefakt-Register als HTML-Tabelle
* Questliste mit aktuellen Aufgaben
* Anmeldeformular für neue Mitglieder
* Dropdown-Menü zur Auswahl eines Reiches
* Nachrichtenfeld für Botschaften an den Rat
* Footer mit Informationen zur Akademie

## Technische Inhalte

* HTML-Grundstruktur
* Semantische HTML-Elemente
* Überschriften (`h1` bis `h3`)
* Absätze (`p`)
* Tabellen (`table`)
* Listen (`ul`, `li`)
* Formulare (`form`)
* Texteingabefelder (`input`)
* E-Mail-Felder (`type="email"`)
* Dropdown-Menüs (`select`)
* Textbereiche (`textarea`)
* Buttons (`button`)
* Externe CSS-Datei (`style.css`)
* Verknüpfung von HTML und CSS

## Lernziel

Ziel dieses Projekts war es, grundlegende HTML- und CSS-Kenntnisse praktisch anzuwenden und verschiedene Seitenelemente miteinander zu kombinieren.

Dabei wurde geübt, Inhalte übersichtlich zu strukturieren und das Layout über eine externe CSS-Datei zu gestalten.

## Motivation

Ich habe dieses Projekt entwickelt, um meine Kenntnisse in HTML und CSS weiter zu vertiefen und eine thematisch zusammenhängende Fantasy-Webseite umzusetzen.

Der Fokus lag auf der Arbeit mit Tabellen, Formularen, Listen sowie der Trennung von Struktur (HTML) und Design (CSS).
