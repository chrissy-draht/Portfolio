# CodeBunker 404 Kontaktformular (HTML)

## Beschreibung

Dieses Projekt simuliert ein Kontaktformular für die geheime Hacker-Zentrale **CodeBunker 404**.

Besucher können Anfragen an das Support-Team senden und dabei verschiedene Formularelemente nutzen. Der Fokus liegt auf dem Umgang mit HTML-Formularen, Benutzereingaben und der strukturierten Erfassung von Informationen.

## Funktionen im Projekt

- Aufgabe 1: Hauptüberschrift erstellen
- Aufgabe 2: Begrüßungstext hinzufügen
- Aufgabe 3: HTML-Formular erstellen
- Aufgabe 4: Eingabefeld für den Codenamen
- Aufgabe 5: Eingabefeld für die E-Mail-Adresse
- Aufgabe 6: Dropdown-Menü für den Anfragegrund
- Aufgabe 7: Radiobuttons für die Dringlichkeit
- Aufgabe 8: Checkboxen für betroffene Bereiche
- Aufgabe 9: Mehrzeiliges Nachrichtenfeld
- Aufgabe 10: Datumsfeld für den Beginn des Problems
- Aufgabe 11: Absende-Button für die Anfrage
- Bonus: Passwortfeld für ein geheimes Codewort

## Technische Inhalte

- HTML-Grundstruktur
- Formulare (`form`)
- Texteingabefelder (`input`)
- E-Mail-Felder (`type="email"`)
- Passwortfelder (`type="password"`)
- Dropdown-Menüs (`select`)
- Radiobuttons
- Checkboxen
- Textbereiche (`textarea`)
- Datumsfelder (`type="date"`)
- Buttons (`button`)
- Labels (`label`)
- Strukturierung mit semantischen HTML-Elementen
